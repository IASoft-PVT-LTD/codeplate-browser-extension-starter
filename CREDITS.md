# Credits

The extension icons in `assets/icons/` are original, drawn for CodePlate by `scripts/make-icons.mjs` (shapes rendered in code, no source images). The logo and interface icons in `src/ui/icons.ts` are original SVG drawings made for this template, and the test pages in `tests/pages/` (text included) were written for it. They're listed in `assets.json` (the icons) with `license: CodePlate-original` and are yours to ship in extensions made from this template.

No third-party images, icons or fonts are included. The extension uses the system font.

When you add assets, list each one in `assets.json` (path, size, where it's used, license, credit) and here, with its author, license and a link to its source. Only use assets the user owns, made themselves, or that are CC0.
